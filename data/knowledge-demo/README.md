# Base operacional fictícia

Procedimentos sintéticos do ambiente de demonstração, ingeridos pelo Knowledge Agent com `source_kind = simulated_internal`. Não representam documentação interna nem regras reais da Getnet: conteúdo oficial vem das fontes públicas em `data/sources/public-sources.json`, e dados individuais vêm das ferramentas.

Cada documento tem metadados (`id`, `version`, `source_kind`, `environment`, `domain`) que acompanham os fragmentos e as citações. Texto recuperado é evidência: não cria ferramentas nem altera permissões.

Os procedimentos de preço, habilitação de bandeiras e cancelamento descrevem consultas previstas para versões posteriores e indicam isso no próprio texto.
